Pikapäivitys

Päivitä-painike voi käynnistää uuden haun lehdistä heti, eikä sinun tarvitse odottaa ajastettua hakua. Siihen tarvitaan GitHub-token, joka tallennetaan vain tähän laitteeseen.

  1. Avaa GitHubin uusi fine-grained token.
  2. Repository access: Only select repositories → uutiset.
  3. Permissions: Actions → Read and write. Muita oikeuksia ei tarvita.
  4. Luo token ja liitä se alle.
